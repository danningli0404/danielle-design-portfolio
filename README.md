# Danielle Li — Design Engineering Portfolio

The source code and assets for Danielle Li's bilingual design engineering portfolio. It presents selected product, interaction, service, and research projects, including TacChat, PureLink, Ice Chamber, and Coco Carry.

Live portfolio: https://danielle-li-design-engineer.dli05.chatgpt.site/

## Run locally

Install dependencies with `pnpm install`, then run `pnpm dev`. The project uses Next.js/React and includes Chinese and English content.

The live site is hosted separately. Pushing to this GitHub repository does not automatically publish changes to that site.

Project images and case-study material are part of Danielle Li's portfolio and should not be reused without permission.
